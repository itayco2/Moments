A row is closed only when its number after is measured.

| PF25 | the live first visit stalled for good at about 130 of 402 MB. With a progress callback, transformers.js asks for each model file twice: first only for its size, as a full download whose headers it reads and whose body it never closes, then for the bytes. Over HTTP/2 (Vercel's CDN) every request shares one connection, and the two unread 200 MB answers stalled it; over HTTP/1.1 each request has its own connection, which is why the local checks passed.
